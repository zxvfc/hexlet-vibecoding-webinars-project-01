# Дайджест публикаций о магнитарах

Раз в час Claude Code ищет в вебе новые публикации по темам из `topics.txt`
(по умолчанию «магнитары»), отбирает их по правилам из `KNOWLEDGE.md`,
сохраняет в `archive.json`, отправляет новые ссылки в Telegram и коммитит изменения
в этот репозиторий. Витрина — страница-архив на claude.ai:
https://claude.ai/artifact/Ge4nsx1Fox1yrD5ikVBtGg (видна только владельцу).

## Файлы

| Файл | Назначение |
|---|---|
| `.claude/skills/digest/SKILL.md` | скилл `/digest` — порядок работы |
| `KNOWLEDGE.md` | правила отбора |
| `topics.txt` | список тем, по одной на строку — источник истины |
| `topics.py` | применение заявок со страницы к `topics.txt`, разбор конфликтов |
| `archive.json` | архив найденных ссылок (`title, url, source, published, found, topic, summary, id`) |
| `state.json` | время последнего «Ничего не нашлось» (локальный, не в git) |
| `send.py` | отправка в Telegram (только стандартная библиотека) |
| `archive.py` | нормализация адресов, проверка дублей, запись в архив, выгрузка на страницу |
| `artifact/index.html` | исходник страницы-архива |

## Telegram

1. **Токен.** Написать [@BotFather](https://t.me/BotFather) → `/newbot` → задать имя и username (оканчивается на `bot`). BotFather пришлёт токен вида `123456789:AA...`.
2. **Chat id.** Написать своему боту любое сообщение (или добавить бота в группу и написать там). Затем открыть
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `result[].message.chat.id`
   (у групп он отрицательный, например `-100...`).
3. **Передать скрипту** — одним из способов:
   - переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
     (в облачном окружении Claude Code — в настройках окружения, раздел переменных);
   - файл `.env` рядом с `send.py` (он в `.gitignore`, не коммитить):
     ```
     TELEGRAM_BOT_TOKEN=123456789:AA...
     TELEGRAM_CHAT_ID=123456789
     ```

Проверка: `python3 send.py "Тест"`.

## Сеть

В обычном чате claude.ai Telegram недоступен (прокси отвечает 403 на `api.telegram.org`).
Нужна сессия Claude Code с сетевым доступом **Full** или **Custom** с доменом `api.telegram.org`.

## Запуск

Вручную в Claude Code: `/digest` (или «запусти дайджест»).

## Расписание

Минимальный интервал планировщика — 1 час.

Задача по расписанию в Claude Code (claude.ai/code) с промптом `/digest`, расписанием раз в час
и режимом «новая сессия на каждый запуск» с этим репозиторием. Каждый запуск:
клонирует репозиторий → применяет заявки на темы → ищет → отправляет в Telegram →
коммитит `topics.txt` и `archive.json` → пушит → обновляет страницу.

Нужно в окружении Claude Code:
- переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`;
- сетевой доступ Full или Custom с доменом `api.telegram.org`;
- доступ к этому репозиторию с правом push.

Локально (cron), если нужно:
```
0 * * * * cd /path/to/repo && claude -p "/digest" --allowedTools "WebSearch,WebFetch,Read,Bash(python3:*),Bash(git:*)"
```

## Темы

Источник истины — `topics.txt`. Менять можно тремя способами:
- на странице-архиве — правка становится заявкой и применяется на ближайшем запуске (в течение часа) с коммитом;
- правкой `topics.txt` прямо на GitHub — подхватится на следующем запуске, страница обновится сама;
- попросить Claude в чате — он сразу сделает коммит.

Заявки — это действия «добавить»/«удалить», они применяются поверх файла, поэтому правки с двух сторон складываются.
Если одну тему меняли в разные стороны, побеждает более позднее действие, и Claude пишет об этом в Telegram.
